# DBS Servis Premium Preview

Premium static demo za DBS Servis D.O.O.

## Vključeno
- responsive VIP/mehanični dizajn
- hero z odprto kabino/servisom tovornjaka
- rezervacija termina
- servisno povpraševanje
- podatki vozila + VIN validacija
- priprava e-pošte na `dbsservisvozil@gmail.com`
- Google Maps povezava
- FAQ
- SEO/Schema.org
- PWA manifest + service worker
- priprava za priklop Formspree/Supabase/lastnega API-ja

## Produkcija
V `CONFIG.formEndpoint` v `index.html` se lahko vnese pravi API endpoint. Telefonska/WhatsApp številka in potrjen delovni čas se dodata pred javno objavo.

## Mobile / desktop visual consistency
The mobile breakpoint intentionally preserves the same premium desktop composition: cinematic hero background, paired CTA buttons, three service cards in a swipeable row, integrations in a horizontal rail, and paired booking/contact panels. This keeps the phone experience visually close to the desktop reference without shrinking the whole desktop page into unreadable text.
